# 主流国产模型发布时间表

> 用途：部分渠道的 `/models` 接口不返回模型创建时间（`created` 字段缺失），同步时的 9 个月时间窗无法按接口数据判定。本文件作为人工维护的发布时间基准，用于校对无 `created` 数据的模型是否在时间窗内。
>
> 覆盖范围：`pi_cache.SERIES_ALLOW` 白名单系列（minimax / mimo / glm / qwen / deepseek / kimi / step / muse / hy）的主要文本类模型。
>
> **注意**：`muse` 系列实为 Meta（美国）模型（如 `meta/muse-glimmer-30b`），并非国产模型，仅因渠道中常见而一并收录，表中标明。
>
> 时间窗参考：以 9 个月窗口计，早于 **2026-02-05** 发布的模型已超出窗口（相对最后更新时间 2026-11-05）。
