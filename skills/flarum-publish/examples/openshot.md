# OpenShot：开源的视频编辑软件

OpenShot Video Editor 是一款屡获大奖、完全免费且开源的视频编辑软件，支持 Linux、Mac 和 Windows 三大平台。它的目标是为全球用户提供高品质的视频剪辑与动画制作工具。

## 主要功能

* 支持跨平台运行（Linux、Mac 和 Windows）
* 基于 FFmpeg，兼容绝大多数视频、音频和图片格式
* 强大的关键帧动画，支持曲线调节
* 与桌面环境深度整合，可直接拖拽文件
* 轨道和图层数量不受限制
* 可对片段进行缩放、裁剪、旋转、剪切及吸附操作
* 视频转场效果丰富，并支持实时预览
* 支持合成、图像叠加及水印添加
* 内置标题模板，可创建标题和字幕
* 支持 2D 动画（如图像序列）
* 支持 3D 动态标题及特效
* 兼容 SVG 矢量图形，可制作矢量标题和演职员表
* 支持滚动式片尾演职员表
* 高级时间线功能，支持拖拽、滚动、平移、缩放和吸附
* 可精确到每一帧，逐帧浏览编辑
* 支持时间映射和片段变速（快放、慢放、正放、倒放等）
* 支持音频混音和编辑
* 内置多种数字视频特效，如亮度、伽马、色调、灰度、色键抠像等
* 实验性支持硬件编解码加速（VA-API、NVDEC、D3D9、D3D11、VTB）
* 支持导入和导出多种通用格式（如 EDL、XML）
* 基于 FFmpeg，可输出多种编码和格式的视频
